# Perfil Profissional

Página pessoal desenvolvida com HTML e CSS para apresentar minha trajetória profissional, formação e links de contato.

## Sobre o projeto

Este projeto foi criado para funcionar como uma landing page profissional, com foco em:

- apresentação pessoal e profissional
- experiência em processos, atendimento e operações
- evolução para a área de tecnologia
- contato com GitHub e oportunidades profissionais

## Tecnologias utilizadas

- HTML5
- CSS3
- Git e GitHub

## Estrutura do repositório

- `index.html` — estrutura da página e conteúdo
- `styles.css` — estilos visuais, layout e responsividade
- `fotos/` — arquivos de imagem utilizados no perfil
- `README.md` — documentação do projeto

## Como visualizar localmente

Você pode abrir o arquivo `index.html` diretamente no navegador ou iniciar um servidor local:

```bash
python3 -m http.server 8000
```

Em seguida, acesse:

```text
http://localhost:8000
```
